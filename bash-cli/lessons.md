# Bash CLI lessons

Ordered outline - a session works through the next lesson you haven't
completed. See "Related skills" in the README before your first one.
Personal progress lives in gitignored `progress/`, not here.

1. Navigation - `pwd`, `ls`, `cd`, path shorthand.
2. Files - create, copy, move, remove, view contents.
3. Search - `grep`, `find`, `which`.
4. Piping and redirection - `|`, `>`, `>>`, `<`, `2>`, `&&`.
5. Permissions - reading and changing `ls -l` modes, `chmod`, `chown`.
