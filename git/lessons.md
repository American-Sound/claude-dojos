# Git lessons

Ordered outline - a session works through the next lesson you haven't
completed. See "Related skills" in the README before your first one.
Personal progress lives in gitignored `progress/`, not here.

1. Setup and status - `init`, `clone`, `status`, `log`.
2. Staging and committing - `add`, `restore --staged`, `commit`, `diff`.
3. Branching - `branch`, `switch`, `merge`.
4. Remotes - `remote`, `fetch`, `pull`, `push`.
5. Undoing things - `restore`, `reset`, `revert`.
